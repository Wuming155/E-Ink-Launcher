# E-Ink-Launcher 精简与修复计划

## A. 删除 FTP 功能(连同依赖)
1. 删除 `app/src/main/java/com/wuming/einklauncher/ftpservice/` 整个目录(FTPService.java、FTPReceiver.java)
2. `gradle/libs.versions.toml`:移除 apache-ftpserver/ftplet-api 条目;`app/build.gradle.kts`:移除对应两行 `implementation`,并移除专为 Apache 依赖加的 `packaging.resources.excludes`
3. `Launcher.java`:删除 `ftpReceiver` 字段、FTP 相关 import、`registerDynamicReceivers` 中的 ftp 注册及 `ftpRegistered` 标志/注销逻辑
4. `SettingFragment.java`:删除 `menu_ftp` 点击分支、`handleFtp`/`startFtpServer`/`stopFtpServer`/`updateFtpStatus`/`getFTPAddressString`、`wifiReceiver`+`ftpReceiver`(均只为 FTP 服务)及 onResume/onPause 中对应注册注销、`updateFtpStatus()` 调用
5. `activity_setting.xml`:删除 `menu_ftp` 菜单项块及 `ftp_status`/`ftp_addr` 两个 TextView
6. 4 个语言的 strings.xml:删除 `setting_cloud_manager_*` 三条

## B. 删除 FileProvider 死配置
- Manifest 中的 `<provider>` 块;删除 `res/xml/filepath.xml`(代码零引用)

## C. 权限清理(Manifest)
- 删除:`INTERNET`、`RESTART_PACKAGES`、`DELETE_PACKAGES`、`WAKE_LOCK`(均零引用)、`ACCESS_FINE_LOCATION`(用户已确认删)、`ACCESS_NETWORK_STATE`(FTP/wifiReceiver 删除后无引用)
- `READ/WRITE_EXTERNAL_STORAGE` 加 `android:maxSdkVersion="32"`
- 保留:`SHUTDOWN`/`REBOOT`(系统应用关机重启菜单)、`REQUEST_DELETE_PACKAGES`、`QUERY_ALL_PACKAGES`、`PACKAGE_USAGE_STATS`、WiFi 两项

## D. 删除 HomeEntranceService(用户已确认删)
- 删除 `model/HomeEntranceService.java`、Manifest 中 service 声明、`Launcher.checkLaunchHomeNotification()` 及调用、2 个语言的 `notification_click_back_launcher` 字符串;顺带消灭 FGS type 崩溃隐患

## E. 删除 WiFi SSID 显示功能(用户已确认删)
- `SettingFragment.java`:`handleShowWifiName()`、`onRequestPermissionsResult` 中 10002 分支、`Manifest` import
- `WifiControl.java`:删除 `reloadWifiName()`;`wifi_status_connected` 字符串中 SSID 拼接逻辑(`connectWifiName`)保留拼接行为不变——仅删权限申请入口

## F. 三个 Bug 修复
1. **权限回调丢失**:`Utils.checkStoragePermission` 改为保存 pending Runnable;`SettingFragment.onRequestPermissionsResult` 增加 10003 分支调用 `Utils` 的新静态方法,授权后继续执行原回调
2. **BACK 键被吞**:`Launcher.onKeyUp` 对 `KEYCODE_BACK` 在 backstack>0 时改为 `return super.onKeyUp(...)`,否则维持消费
3. **管理模式 UI 残留**:`AppItemBinder.clearItem` 增加 `menuContainer.setVisibility(View.GONE)`

# E-Ink Launcher

`E-Ink Launcher` is an Android launcher for Electronic paper book.

面向墨水屏（E-Ink）设备的 Android 桌面启动器。

![E-Ink Launcher](app/release/preview.png)

## 关于本仓库

本仓库是基于上游的独立维护分支：

- 包名由 `cn.modificator.launcher` 更改为 `com.wuming.einklauncher`，与上游应用相互独立，可共存安装
- 不再沿用上游的发布渠道与联系方式，后续由本仓库独立发布与维护
- 上游原始版权与协议声明予以保留
